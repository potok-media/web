---
title: "Первый плагин"
description: "Манифест, точка входа, запуск и отладка плагина Potok."
---

Создайте папку с двумя файлами: `manifest.json` и `index.js`.

## Манифест

```json title="manifest.json"
{
  "id": "my-first-plugin",
  "name": "Мой первый плагин",
  "version": "1.0.0",
  "entrypoint": "index.js",
  "permissions": ["ui-notifications"],
  "slots": [{ "id": "hello", "slotName": "home-rows-top", "title": "Привет" }]
}
```

`id`, `name` и `entrypoint` обязательны. Укажите разрешения только для используемых API. Поля, разрешения и точки встраивания описаны в [спецификации манифеста](/wiki/api/manifest/).

## Точка входа

```js title="index.js"
const { ui } = PotokSDK;
const { VStack, Heading, Button } = ui.components;

ui.render(
  VStack()
    .spacing(12)
    .child(Heading("Привет, Potok!"))
    .child(Button("Нажми меня").onClick(() => {
      ui.showHUD("success", "Работает!");
    })),
  "hello"
);
```

UI строится из [компонентов SDK](/wiki/components/): плагин описывает дерево, а хост отображает его. В песочнице можно использовать те же билдеры напрямую; для просмотра примера уберите второй аргумент `ui.render` — идентификатор слота.

## Проверка и установка

1. Откройте [песочницу](/wiki/sandbox/) и проверьте интерфейс и обработчики.
2. Опубликуйте папку плагина по HTTP и установите её URL в настройках расширений Potok.
3. Проверьте вклад плагина в слот и сообщения инспектора расширений.

Песочница предоставляет тестовые реализации HTTP, хранилища, уведомлений и навигации. Для проверки прав, регистрации источников и интеграции с реальными данными установите плагин в приложение.
