Choose an example or write code and click **Run** to try Potok's components and notifications.

<Sandbox lang="en" />

The preview opens automatically. Notifications, dialogs, the episode picker, and reactive components use Potok's real UI. Event logs remain visible in both the editor and preview.

The preview theme is independent of the documentation theme and does not change saved app settings. Use fullscreen preview or a separate sandbox tab to check layout sizes.

HTTP, storage, navigation, and video playback use test implementations. Install your plugin in the app to verify its full integration.
