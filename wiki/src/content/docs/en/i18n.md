<a id="t"></a>

`PotokSDK.i18n` — host strings and custom dictionaries. Language syncs with the host.



## PotokSDK.i18n.t

Returns a translated string by key namespace:path for the current language. Supports {{var}} interpolation and plural forms via { count }.

```javascript
const { i18n, ui } = PotokSDK;

// Read host UI strings
const closeLabel = i18n.t("common:actions.close");

// Plugin-owned namespace
i18n.addResourceBundle("en", "myplugin", {
  greeting: "Hello, {{name}}!"
});

ui.render(Text(i18n.t("myplugin:greeting", { name: "Potok" })));
```

<a id="addResourceBundle"></a>

## addResourceBundle

Registers a plugin dictionary for a language and namespace. Example: `addResourceBundle`("en", "`myplugin`", { greeting: "Hi {{name}}" }).

<a id="registerTranslations"></a>

## registerTranslations

Bulk registration: { en: { `myplugin`: {...} }, ru: { `myplugin`: {...} } }. Also notifies the host to persist plugin translations.

```javascript
PotokSDK.i18n.registerTranslations({
  en: { myplugin: { title: "My Plugin" } },
  ru: { myplugin: { title: "Мой плагин" } }
});
```

<a id="onLanguageChange"></a>

## onLanguageChange

Subscribe to UI language changes. Returns an unsubscribe function. Redraw plugin UI when the host language changes.

```javascript
const { i18n } = PotokSDK;

const unsubscribe = i18n.onLanguageChange((lng) => {
  console.log("Language changed:", lng);
  redraw();
});
```

Current language is available as `PotokSDK.i18n`.language (e.g. "en", "ru").
